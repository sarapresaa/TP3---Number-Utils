# TP3 — Number Utils

Biblioteca em Java com funções estatísticas e ordenação de listas. Exercício académico desenvolvido no âmbito de Tecnologias da Informação.

## Funcionalidades
- Cálculo da média
- Cálculo da mediana
- Cálculo da moda
- Ordenação de listas

## Tecnologia
Java

## Código
Os ficheiros do projeto encontram-se na pasta `Number Utils/`.
